# Tadcu — Episode 1: "The Great Sheep Escape"

An episode of the **Tadcu** animated cartoon series. Tadcu (Welsh for "Grandpa"),
his sheepdog Bryn, and one very open farm gate.

## What's in here

| File | Description |
| --- | --- |
| `index.html` | The complete animated episode — self-contained, no dependencies. Open it in any browser. |
| `script.md` | Full script, shot list and storyboard notes. |

## How to watch

Open `index.html` in a browser (Chrome, Edge, Firefox or Safari), then press the
▶ Play button. Controls: play/pause, restart, scene skip, and a progress bar.

## Series bible

- **Tadcu** — A retired hill farmer. Flat cap, big grey beard, cardigan, a
  thermos of tea that is never allowed to run out. Speaks English sprinkled
  with Welsh phrases (*Bore da!*, *Diolch yn fawr!*). Warm, stubborn, slyly funny.
- **Bryn** — Tadcu's border-collie. Does all the actual work. Long-suffering.
- **The Sheep** — Ninety-nine ewes, individually named but collectively referred
  to as "the girls".
- **Setting** — Cwm Twp, a flat-topped valley somewhere in mid-Wales. Dramatic
  hills, tiny cottage, bigger gate.

## Production

Style: flat 2-D vector shapes with thick outline-free silhouettes, limited
palette (greens, cream, slate grey, warm red-orange), baked into HTML/CSS/SVG.
Runtime: ~1 minute per scene cycle, 5 scenes.
